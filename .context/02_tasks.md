# タスク管理 (02_tasks.md)

## 進行中 (In Progress) / 直近の課題
- [ ] **【課題A】縦型動画（9:16）および 4:3 動画の解像度・アスペクト比不備の改修**
  - **現状の病巣**: `v3.0/main.py`（L4256〜4263）の動画書き出し処理で、解像度が常に横長 16:9（1920x1080 / 1280x720 / 3840x2160）固定で FFmpeg に渡されている。そのため、設定で「9:16 (縦型)」や「4:3」を選択しても、16:9の横長画面の中央に巨大な黒帯（ピラーボックス）付きで配置された動画が出力される。
  - **対応方針**: `combo_exp_res` と `ratio_combo`（アスペクト比）の組み合わせから真の動画解像度（9:16なら `1080x1920` / `720x1280`、4:3なら `1440x1080` / `960x720`）を算出して FFmpeg および OpenGL オフスクリーン FBO に設定し、外枠の不要な黒帯を排除する。
- [ ] **【課題B】タイトルカード・クレジット表示の実幅相対スケーリング**
  - **現状の病巣**: タイトルの描画座標・フォントサイズ計算が 1920px 横幅基準で固定されているため、縦型動画（幅1080px）時にタイトルが動画枠からはみ出す。
  - **対応方針**: 描画先の実際の幅 $W$ に応じた動的スケーリング・中央配置・マージンクリッピングを適用する。
